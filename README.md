# Factory Ledger Analytics

NeoForge-Addon (Minecraft 1.21.1, Java 21) für **Create: Factory Ledger**: Produktionsdiagramme,
Langzeit-Historie und Offline-Aufzeichnung.

**Status:** Phase A – Analyse der Originalmod (noch kein Code).

Die Fremd-JARs (Factory Ledger, Create, Drawer-Mods) gehören in `libs/` und werden nicht eingecheckt.
